# 📚 Personal Library Manager

A clean and simple Streamlit app for managing your personal book collection — complete with cover uploads, search, filters, read status tracking, and SQLite storage.
Built to be fast, responsive, and easy to use on any device.

# 🚀 Features

- ✔️ Add books with title, author, genre, year, and optional cover image
- ✔️ Upload book covers (stored locally)
- ✔️ Mark books as Read / Not Read
- ✔️ Delete books with one click
- ✔️ Search by title or author
- ✔️ Filter by genre
- ✔️ Books stored safely using SQLite
- ✔️ Fully responsive UI
- ✔️ Smooth hover animations and clean card design
- ✔️ Auto-created folders and database
- ✔️ Works offline — everything is local

# 🏗️ Tech Stack

- Python 3

- Streamlit

- SQLite

- Pillow (PIL) for images
